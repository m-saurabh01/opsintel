## Performance & Capacity

### Load Capacity: 1000-3000 Concurrent Users

**Single Machine** (up to 1000 users):
- Uvicorn with 4-8 workers
- SQLite FTS5 search
- Local file storage
- Service Worker browser cache

**Hardware**: 4GB RAM, 2-core CPU (minimum)

**Multi-Machine** (1000-3000 users):
- Nginx load balancer (least-conn)
- PostgreSQL database (replace SQLite)
- NFS or S3 file storage
- Redis cache layer
- 3-5 backend instances (500-1000 users each)

**Hardware per Instance**: 4GB RAM, 2-core CPU

### Caching Strategy Implemented

| Layer | Technology | TTL | Method |
|-------|-----------|-----|--------|
| **Static Assets** | HTTP Cache-Control + ETag | 1 year | Vite hash-based naming |
| **API Search** | HTTP Cache-Control | 60 seconds | Network-first (Service Worker) |
| **Document Metadata** | HTTP ETag | 1 hour | Cache-first (HTTP 304) |
| **File Previews** | Browser IndexedDB | Until cleared | Service Worker cache-first |
| **AI Responses** | In-memory (optional Redis) | 1 hour | (Future: distributed cache) |

**Service Worker** automatically:
- Caches static assets on first load
- Stores search results for 60 seconds
- Caches file previews in IndexedDB
- Falls back to cached data when offline

### Response Time SLAs (Target)
- Search: p95 < 200 ms
- Document fetch: p95 < 100 ms
- File preview: immediate (cached)

## Known Limitations & Future Work

### Current Limitations
1. **SQLite for single machine only** — production use at 2000+ concurrent users requires PostgreSQL
2. **No OCR support** — text extraction requires embedded text in PDF
3. **Mobile UI not optimized** — desktop-first design
4. **No end-to-end encryption** — data transmitted in cleartext (use HTTPS reverse proxy)
5. **AI responses not cached** — optional Redis needed for distributed caching

### Future Enhancements
1. **PostgreSQL support** — for multi-machine deployments
2. **Redis caching layer** — for AI responses and search results
3. **Elasticsearch integration** — for large document collections (100k+)
4. **Multi-language support** — UI and search
5. **Document version history** — track changes
6. **Advanced search** — boolean operators, field-specific queries
7. **Export to ZIP** — batch download documents
8. **SAML/SSO integration** — enterprise authentication
